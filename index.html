Support

Help for preparing and presenting your worship service.

Contact support

Contact Kenny Renaud at kenrend@gmail.com for help with SELAHVOIX.

Include your SELAHVOIX version and build number, macOS version, Mac model, and the steps that led to the problem. If possible, use a small example without private content.

Before sending a screenshot, log or service file, check it for personal information, private lyrics or other content you do not want to share. Logs can contain filenames and paths.

Prepare, preview, present

Arrange songs, Bible readings, text and media into a service. Select a page to prepare it in Preview, then choose Go Live to update the Live monitor. The Output and Stage controls manage separate display windows.

You can prepare a service without opening an external display. No SELAHVOIX account is required.

Add the included content

Open File → Included Bibles, hymns, themes and credits to add the World English Bible (engwebp), the French Louis Segond 1910 Bible, two historic hymns and two themes.

Original Amber Light, Ocean Silk and Violet Drift backgrounds include still images and motion loops. Existing libraries are preserved. If moving from an older Mac version, import your previous libraries before adding starter content, and keep a backup until you have checked the migration.

Import slides and media

Import PDF for static slide appearance or editable .pptx for supported text, shapes and images. Editable PowerPoint import does not retain animations or embedded video playback. Export older .ppt files to PDF or .pptx in your presentation software first.

Import only content you have permission to use. Keep referenced media files available: saving a service does not embed all external media. File → Check missing media helps find and relink missing files.

Use the phone remote

Remote control is off by default. Start it only on a trusted local network, use the PIN shown by the app, and stop it when finished.

The local connection uses unencrypted HTTP. Do not expose its address or port to the public internet.

Open older services

NDI input/output and automatic PowerPoint slide-image conversion are not included in version 1.0. Existing NDI items display an unavailable placeholder while keeping their saved source settings. Keep a backup before editing an older service.

Manage your files

Services are saved where you choose. Libraries, settings, recovery data, file-access bookmarks and logs are also stored locally by the app. Deleting a service does not remove those other files.

Back up your work before changing or removing app data. External media, exported files and backup or cloud-synced copies are managed separately. See the privacy policy for more information.

About this version

SELAHVOIX 1.0 is a free worship presentation app designed for Apple Silicon Macs. This support page covers the macOS version.
